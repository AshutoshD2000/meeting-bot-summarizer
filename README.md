# MeetingBot – AI Meeting Summarizer

A Flask-based web application that generates structured meeting summaries using AI.

## Features

- Create meeting summary
- Structured output (Summary, Key Points, Decisions, Action Items, Agenda)
- Download summary as PDF
- Meeting history dashboard
- Search & filter
- REST API endpoints
- SQLite database storage
- Bootstrap responsive UI

## Tech Stack

- Python
- Flask
- SQLite
- Bootstrap
- ReportLab (PDF generation)
